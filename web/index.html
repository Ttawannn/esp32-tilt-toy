กำลังตรวจไฟล์เฟิร์มแวร์…

ต่อบอร์ดด้วยสาย USB ที่ส่งข้อมูลได้ กดปุ่มด้านล่าง
แล้วเลือกพอร์ตของ ESP32 ในหน้าต่างเบราว์เซอร์

แฟลช USB ผ่าน Chrome / Edge บนคอมพิวเตอร์เปิดหน้านี้ผ่าน HTTPS หรือ localhost เพื่อแฟลช

↓ ดาวน์โหลด .bin

รุ่นทดลอง · คอมไพล์ครบตามโปรไฟล์ · ยังต้องทดสอบกับจอจริง

ผังต่อสาย +
ขาของอุปกรณ์ESP32-C6

จอและ GY-521 ใช้ลอจิก 3.3V และกราวด์ร่วมกัน ตรวจ VCC / BL ของโมดูลก่อนต่อ ไม่ต่อ LED เปล่าเข้าขา GPIO โดยตรง

ปุ่มใช้งานเพิ่มต่อ GPIO2 ↔ GND · ปุ่ม BOOT บนบอร์ดใช้เข้าโหมดแฟลช

ดูข้อมูลโมดูลจอ ↗
ถ้าไม่เจอพอร์ต หรือจอไม่แสดงภาพ +

ลองสาย USB data ปิด Serial Monitor แล้วกด BOOT ค้างระหว่างเสียบ USB จากนั้นปล่อย BOOT และลองแฟลชอีกครั้ง

จอแต่ละโมดูลอาจใช้ค่า inversion / SPI ต่างกัน ปรับได้ในเว็บบนเครื่อง หาก ST7735 ภาพเหลื่อม หรือ OLED ใช้ SH1106 ต้องแก้โปรไฟล์ก่อน build เพิ่มเติม

ตัวแฟลชจะแสดงตัวเลือกติดตั้งและล้างข้อมูล การล้าง flash จะลบค่าที่เคยบันทึกไว้
