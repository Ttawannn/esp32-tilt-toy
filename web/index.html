    No port, or a blank display?+
    Try a USB data cable, close Serial Monitor, and hold BOOT while plugging in USB. Release BOOT and try flashing again.
    Modules may need different inversion or SPI settings; change them from the device web page. An offset ST7735 image or an SH1106 OLED needs an adjusted profile and a new build.
    The installer offers installation and erase options. Erasing flash deletes saved settings.
